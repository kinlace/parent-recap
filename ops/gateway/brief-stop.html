Stop the Parent Recap Brief

Parent Recap is a program on your family's own computer. It writes the evening Brief there and sends it through this address; there is no mailing list to leave here.

To stop the Brief for one person, the person who set up Parent Recap removes that address from the Recipients: ask Claude or Codex "remove <address> from the Brief", or delete it under email.to in ~/.family/config.yaml. To stop it for everyone, ask Claude or Codex to "uninstall Parent Recap".

Iltakoosteen lopettaminen

Parent Recap on ohjelma perheesi omalla tietokoneella. Sen asentanut henkilö voi poistaa osoitteesi vastaanottajista (Claudelta tai Codexilta: "poista <osoite> iltakoosteesta", tai email.to tiedostossa ~/.family/config.yaml) tai poistaa koko ohjelman ("uninstall Parent Recap").

停止接收家庭日报

Parent Recap 是运行在你家自己电脑上的程序。安装它的人可以把你的地址从收件人中删除（对 Claude 或 Codex 说"把 <地址> 从日报里删除"，或在 ~/.family/config.yaml 的 email.to 中删掉），或者卸载整个程序（"uninstall Parent Recap"）。
