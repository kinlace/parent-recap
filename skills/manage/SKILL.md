# Parent Recap management

**Reply in the language the user writes in**, not the language of this skill: English if they write English, Chinese if they write Chinese, and switch if they switch. That never changes the language their Brief comes in; only an explicit request does (see "Change someone's language" below). In Chinese, call the Brief 日报 and Weekend Picks 周末活动推荐; in Finnish, kooste and viikonlopun vinkit; in English or any other language, say Brief and Weekend Picks. Commands, config keys and file paths stay as written.

`FB=~/FamilyBrief/app/.venv/bin/family-brief`, `PY=~/FamilyBrief/app/.venv/bin/python`. **PLUGIN** is the plugin root folder, two levels above this skill's folder (it contains `install.sh`); if unsure, run `ls -d ~/.claude/plugins/cache/*/parent-recap/*/ | sort -V | tail -1`; for an install from the release zip, `~/FamilyBrief/plugin` is also the plugin root.

If `~/.family/config.yaml` doesn't exist, Parent Recap hasn't been set up yet: use `/parent-recap:setup` instead.

## Rules (same as setup)

- Secrets (passwords, App Passwords, tokens, MyClub calendar links) are only typed in the user's own Terminal, never in the chat
- The config holds the MyClub links: don't open or print the whole file. View it with `grep -v myclub_ical_url ~/.family/config.yaml`, and make changes with commands that don't print the file
- Don't print mail or chat text: diagnose with `$FB doctor` and the last few lines of the logs; don't run `$FB collect`
- Back up before changing the config: `cp ~/.family/config.yaml ~/.family/config.yaml.bak-$(date +%Y%m%d%H%M)`
- Commands that need `sudo`: only show them, and let the user run them

## Check the status first

```bash
$FB doctor
$FB schedule status
```

`doctor` shows ✅ / ⚠️ / ❌ for each item, with what to do. doctor checks WhatsApp with the scheduled job's Python on its own. Always put `bg` in commands that read WhatsApp (for example `$FB bg discover whatsapp-chats`); without it they can't read it from here.

For symptoms and fixes, look up the symptom in the table in `PLUGIN/docs/troubleshooting.md`.

## Common tasks

| What the user wants                                                  | How                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Move up a grade / change class                                       | Follow "New school year" in `PLUGIN/docs/config.md`: change grade and class_name, run `$FB bg discover whatsapp-chats` to find the new group names                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Add a WhatsApp group                                                 | Run `$FB bg discover whatsapp-chats`, copy the group name exactly into `whatsapp.chats`, and mark its kid and label                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Add or change a Kid's MyClub calendar                                | The user copies the Kid's calendar subscription link from MyClub ("MyClub" in `PLUGIN/docs/sources.md`) and runs `$PY ~/FamilyBrief/app/scripts/setup_myclub.py "<Kid's name>"` in Terminal. The link carries a personal token: don't let the user paste it in the chat, and don't write it into the config yourself                                                                                                                                                                                                                                                                                     |
| Mail from a school or club isn't in the Brief                        | Find its sender domain with `$FB discover gmail-senders` and add it to `gmail.allowlist_domains`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Add or remove a recipient                                            | Change `email.to` (Brief) or `email.weekend_to` (Weekend Picks). Ask a new person's language: a plain address reads `summary_language`, anyone else is `{address: ..., language: <code>}` ("Recipients in their own language" in `PLUGIN/docs/config.md`), then run `$FB language <code>` for it. If the change moves who is first in `email.to`, say that the Brief is then written in the new first Recipient's language, and Google Calendar events and the archive follow it                                                                                                                         |
| Change someone's language ("from now on send my Brief in English")   | Only on an explicit request (see the top of this file). If more than one parent uses this Mac, confirm whose address "my" is. Set that entry in `email.to` (and `email.weekend_to`, if they're there) to `{address: ..., language: <code>}`, or back to a plain address if the new language is `summary_language`, then run `$FB language <code>`. If it's the first entry in `email.to`, say that the Brief is then written in that language, and Google Calendar events and the archive follow it                                                                                                      |
| Change the Brief time                                                | Change `schedule.daily_hour` / `daily_minute`, run `$FB schedule install`, then give the user the new pmset command                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Turn Weekend Picks on or off                                         | Change `weekend_events.enabled` (ask for preferences when turning on), then run `$FB schedule install`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Turn on pilot feedback (⭐ / ❌ links)                               | Pilot families only. First tell the user every point the parents must know from the "Pilot feedback" section of `PLUGIN/docs/config.md`, and change the config only once they agree. If there's already a `feedback` section, set `enabled` to `true`; if not, have the user paste the whole section the team sent, as that section describes                                                                                                                                                                                                                                                            |
| Turn off pilot feedback                                              | Set `feedback.enabled` to `false`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Switch from ics attachments to writing Google Calendar automatically | The plugin doesn't include a Google app file. If `~/.family/calendar_credentials.json` is missing, ask the user for the file's path (pilot families use the file the maintainers sent separately; everyone else creates their own by following "Creating your own Google app" in `PLUGIN/docs/sources.md`); the file contains a secret, so don't let the user paste its contents. Save it with the command in step 1 of google mode under "Calendar" in `sources.md`. Then set `google_calendar.mode: google` and have the user run `$PY ~/FamilyBrief/app/scripts/setup_google_calendar.py` in Terminal |
| Google Calendar authorization expired                                | Run `$PY ~/FamilyBrief/app/scripts/setup_google_calendar.py` again in Terminal. New events from while it was expired are already attached to the Brief as .ics, and re-authorizing won't write them twice. If it expires every 7 days with their own app, the app is still in "Testing": publish it following step 4 of "Creating your own Google app" in `sources.md`                                                                                                                                                                                                                                   |
| Gmail sign-in fails                                                  | The user creates a new one at https://myaccount.google.com/apppasswords and runs `$PY ~/FamilyBrief/app/scripts/setup_gmail_imap.py address` in Terminal                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Claude summary fails (Credit / 403)                                  | The user runs `claude setup-token` in Terminal, then `$PY ~/FamilyBrief/app/scripts/setup_claude_token.py`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Codex summary fails (Codex is ❌ in doctor)                          | The user opens the Codex app, signs in again with their ChatGPT account, then runs `$FB doctor`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Switch from Claude to ChatGPT, or back                               | Change `llm.backend` (`claude` or `codex`), authorize following the "AI login" section of `PLUGIN/docs/sources.md`, then run `$FB doctor`                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Wilma not signed in                                                  | The user runs `wilma` in Terminal to sign in again                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Send one Brief by hand                                               | `$FB bg run --lookback-hours 48` (really sends email; `bg` is needed to read WhatsApp). Add `--dry-run` to only preview. Allow it 15 minutes (or run it in the background); don't retry while it's going                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Upgrade to a new plugin version                                      | Follow the "Upgrading" section of `troubleshooting.md`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Uninstall                                                            | Follow the "Uninstalling" section of `troubleshooting.md`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |

After changing the config, run `$FB doctor` once and confirm there's no ❌.

## Check the version

```bash
cat ~/FamilyBrief/app/VERSION; grep '"version"' "PLUGIN/.claude-plugin/plugin.json"
```

If the two version numbers differ, the plugin has been updated but the program hasn't caught up. Run `install.sh` again as described in "Upgrading".
