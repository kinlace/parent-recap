# Brand marks

| File | Use |
| --- | --- |
| `parent-recap-mark.svg` / `.png` | The Parent Recap logo: three lines that get shorter and end in one amber dot, for many messages boiled down to one short Brief. Used in the READMEs, as the site's favicon and in its header. |
| `kinlace-mark.svg` / `.png` | The Kinlace mark: two interlaced rings, on a transparent background. For light backgrounds. |
| `kinlace-avatar.svg` / `.png` | The Kinlace mark on the cream background, with room for a round crop. The GitHub organization avatar. |

Colors: dark brown `#2b2622`, amber `#c8731a` (`#efa24a` on dark), cream `#f4eee3`. They are the colors of parentrecap.com.

The PNG files are 512 px renders of the SVG files. Change the SVG, then render it again.
