## Agent skills

### Issue tracker

Issues live in GitHub Issues for `zhao-hanbo/family-brief`, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

Before publishing a spec or tickets, record in `docs/adr/` (via `/domain-modeling`) every decision in them that clears that skill's ADR bar and has no ADR yet.
